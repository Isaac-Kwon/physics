# Hub — 토픽 지도

- 경로: `/{lang}/`
- 장면 디렉터리: `src/scenes/hub/`
- 역할: 독립된 토픽 페이지들의 입구이자, 토픽 사이의 **연결을 한눈에 보여주는 지도**.
- 핵심 메시지: **"보이지 않는 것을 보는 방법"** — 서로 다른 질문들이 같은 도구와 같은 물리로 이어져 있다.
- 구현 시기: Phase 1 에 뼈대 (모든 카드 "곧 공개"), 토픽이 출시될 때마다 활성화.

## 구성

| # | 구간 | 화면 | 패턴 |
|---|---|---|---|
| 1 | 히어로 | 어둠 속에서 하나의 빛나는 궤적이 지나감 → 사이트 제목과 부제 | P4 (짧게, 한 화면) |
| 2 | 토픽 지도 | 세로 **길이 스케일 축** 위에 토픽 카드 배치 + 카드 사이 연결선 | 정적 + 호버 인터랙션 |
| 3 | 토픽 목록 | 모바일/접근성용 단순 카드 목록 (지도와 같은 정보) | — |
| 4 | 푸터 | 용어집, about, 언어 전환 | — |

### 토픽 지도 레이아웃 (초안)
```
 스케일 축                토픽 (연구 대상)                        도구
 10²⁶ m  ─── ● Dark Matter         ─┐
 10¹¹ m  ─── ● Neutrinos            ─┼──────────────  ◆ Detectors
 10⁻⁵ m  ─── ● Semiconductor Det.   ─┤                  (축 밖, 모든 토픽과 연결)
 10⁻¹⁵ m ─── ● Heavy-Ion            ─┘
```
- 토픽 카드는 각자의 **액센트 색** 과 히어로 장면의 짧은 루프 썸네일을 가진다.
- 연결선: `src/content/connections.yaml` 에서 생성. 선에 호버/탭 → 연결 이유 한 줄 ("실리콘 CCD 로 전자 하나를 센다").
- 카드에 호버 → 그 토픽과 연결된 선만 강조.
- 미출시 토픽: 흐린 카드 + "곧 공개", 연결선은 점선.
- Detectors 는 스케일에 속하지 않는 "도구" 이므로 축 옆에 별도로 둔다 (확정 전, 디자인 단계에서 재검토).

## 장면 / 상태
- `hub.hero` — 단일 궤적 애니메이션 (가벼움, 첫 화면 성능 우선)
- `hub.map` — 2D SVG/Canvas 로 충분. 무거운 WebGL 불필요

## UI
- 상단: 로고, 토픽 메뉴 (드롭다운, 순서 없음), 언어 전환 (KO · EN · IT)
- 첫 방문자에게 "처음이라면?" 안내 없음 — 어느 토픽에서 시작해도 된다는 것이 원칙

## 확장 (선택, §8 D5)
- 우주 → 쿼크 연속 줌 연출. 모든 토픽의 히어로 장면이 있어야 효과적이므로 모든 토픽 출시 후 검토.
