# 용어 대조표 (초안) — KO · EN · IT

이 표는 `src/content/glossary/<term>.yaml` 로 옮겨질 시드 데이터다.
**모든 항목은 원어민·전공자 검토 전의 초안**이다 (특히 이탈리아어).

규칙
- 본문에서 용어 첫 등장 시: `한국어 (English, 약어)` 형태로 병기.
- 약어(QGP, TPC, MAPS 등)는 세 언어 모두 영어 약어를 그대로 사용.
- `id` 는 영어 kebab-case, 용어 YAML 파일명과 동일.
