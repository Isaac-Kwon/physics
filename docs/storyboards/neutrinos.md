# Neutrinos — 중성미자 검출기의 검출 방법

- 경로: `/{lang}/neutrinos/`
- 장면 디렉터리: `src/scenes/neutrinos/`
- 스케일 여정: 태양 (10¹¹ m) → 지구를 관통 → 검출기 탱크 → 단일 상호작용 꼭짓점
- 액센트: 체렌코프 블루
- 핵심 메시지: **"거의 아무것과도 반응하지 않는 입자를 잡으려면, 거대한 질량과 끝없는 인내, 그리고 아주 영리한 신호가 필요하다."**

## 층별 구성
층 5개: `hook` (T0) → `ghost` (T1) → `sources` (T2) → `detection` (T3) → `frontier` (T4)

### 1. Hook — `hook` · T0
- 비주얼: 화면을 가로지르는 무수한 희미한 선들이 손(또는 지구)을 그대로 관통 (P1)
- 숫자 (P4): 지구에서 태양 중성미자 플럭스 **≈ 6.5 × 10¹⁰ /cm²/s** — "지금 당신의 엄지손톱을 매초 약 600억 개가 지나간다"
- 후속: 그중 평생 동안 당신 몸에서 반응하는 것은 ~1개 정도

### 2. 유령 입자 — `ghost` · T1
- Primer `standard-model` (렙톤의 자리)
- Pauli 의 "필사적인 해결책" (1930) — 베타 붕괴의 에너지 보존 문제
- 전하 없음, 약한 상호작용만, 질량은 거의 0 (하지만 0은 아님!)
- **세 가지 맛 (νₑ, ν_μ, ν_τ)** 과 **진동** — 맛이 날아가는 동안 바뀐다
  - 위젯(P5): 거리 L / 에너지 E 슬라이더 → 맛 확률 그래프 (2-flavor → 3-flavor)
  - 태양 중성미자 문제 (Homestake 의 1/3 결손) → SNO / Super-K 로 해결 → 2015 노벨상
- Deeper: P(ν_α→ν_β) = sin²2θ · sin²(1.27 Δm² L / E)

### 3. 어디서 오고, 어떻게 반응하는가 — `sources` · T2
- 반응 방식 부분이 Primer `weak-interaction` 의 원본
- **출처 지도** (P6 가로 갤러리, 에너지 축 위에 배치): 우주배경 중성미자 (meV) · 지구중성미자 · 원자로 (MeV) · 태양 · 초신성 (SN 1987A) · 대기 (GeV) · 가속기 빔 · 천체물리 (PeV 이상)
- **반응 방식**: 
  - 하전류 (CC): ν 가 짝 하전 렙톤으로 변신 → 맛을 알 수 있다
  - 중성류 (NC): ν 가 에너지만 남기고 떠남 → 맛 무관
  - 탄성 산란, 역베타붕괴, 결맞음 핵 산란 (CEvNS)
- 단면적의 작음 (GeV 에서 ~10⁻³⁸ cm²) → "검출기 크기 = 수 킬로톤 ~ 1 km³"

### 4. 검출 방법 카탈로그 — `detection` · T3
이 페이지의 중심. 각 방법 = 하나의 핀 고정 장면 (P1), "이 신호가 어떻게 생기는가" 를 분해.
방법 앞에 해당 Primer 삽입: 물 체렌코프 ← `cherenkov`, 액체 섬광체 ← `scintillation`, LArTPC ← `tpc`. 방법 소개 전에 `underground-lab`.

각 방법은 Detection Walkthrough (P9, PLAN §3.5) 형식: ① 무엇을 → ② 신호가 생기기까지 (3–5 단계 원리도) → ③ 읽어내는 것 → ④ 핵심 트릭. 대표 실험 하나가 그림의 주인공이고, 같은 원리의 실험은 한 줄로만.

**A. 방사화학 — 원자를 세다** (대표: Homestake · 같은 원리: GALLEX/GNO (LNGS), SAGE)
- ② 지하 거대 탱크의 세정액 → 중성미자가 염소 원자핵 하나를 아르곤으로 바꿈 → 몇 주 동안 모인 아르곤 원자 수십 개를 화학적으로 뽑아냄 → 방사성 붕괴로 하나씩 셈
- ③ 몇 개가 왔는가 (방향·시간은 모름)
- ④ 트릭: 수백 톤 속 원자 수십 개를 찾아내기 — "모래사장에서 특정 모래알 찾기" 숫자 연출

**B. 물 체렌코프 — 빛의 고리** (대표: Super-Kamiokande · 같은 원리: Hyper-K)
- ② 중성미자가 물속 원자와 반응 → 빠른 하전 입자 생성 → 물속 빛의 속도보다 빨라 **원뿔 모양의 빛** (Primer `cherenkov`) → 벽의 광센서에 **고리** 로 찍힘
- ③ 고리의 위치·크기 → 방향과 에너지, 고리의 모양 → 입자 종류
- ④ 트릭: 뮤온은 **선명한 고리**, 전자는 샤워 때문에 **번진 고리** → 중성미자의 맛을 구별 — 위젯 `RingClassifier` "고리 맞히기" (탱크 전개도 위)
- Deeper: 체렌코프 각 cos θ = 1/(nβ), 물에서 ~42°

**C. 액체 섬광체 + 역베타붕괴 — 두 번 깜빡이면 진짜** (대표: JUNO · 같은 원리: RENO (한국), Daya Bay, KamLAND)
- ② 원자로의 반중성미자가 양성자와 반응 → 양전자 + 중성자 → 양전자가 즉시 섬광 (첫 번째 빛, Primer `scintillation`) → 중성자가 잠시 돌아다니다 원자핵에 잡히며 두 번째 빛
- ③ 첫 번째 빛의 밝기 → 중성미자 에너지
- ④ 트릭: **지연 일치** — 정해진 시간 간격으로 같은 자리에서 두 번 깜빡여야 진짜. 우연한 배경은 이렇게 짝지어지기 어렵다 — 위젯 `IbdCoincidence` (시간 창을 조절하면 배경이 사라지는 체험, 오실로스코프 화면)

**D. 액체 아르곤 TPC — 전자 사진기** (대표: DUNE · 같은 원리: ICARUS (Rubbia, LNGS 에서 시작), MicroBooNE)
- ② 반응에서 나온 입자들이 아르곤을 전리 → 전자들이 전기장을 따라 몇 m 를 표류 → 끝의 와이어 평면들에 도착 (Primer `tpc`) → 와이어 위치 + 도착 시간 = 3D 궤적
- ③ 거품상자 사진처럼 세밀한 **반응 전체의 그림** — 어떤 입자들이 어디로 나갔는지
- ④ 트릭: 아르곤이 매우 순수해야 전자가 몇 m 를 잃어버리지 않고 표류한다 — 와이어 신호(2D) → 3D 궤적으로 재구성되는 장면

**E. 중성미자 망원경 — 바다와 얼음을 검출기로** (대표: KM3NeT (지중해, 시칠리아 앞바다) · 같은 원리: IceCube (남극), Baikal-GVD)
- ② 자연의 물·얼음 속에 광센서를 매단 줄 수백 개 → 고에너지 중성미자가 만든 뮤온이 지나가며 체렌코프 빛 → 각 센서에 빛이 도착한 **시간 순서**
- ③ 도착 시간의 순서 → 날아온 **방향**, 빛의 총량 → 에너지
- ④ 트릭: 지구 아래쪽에서 올라오는 뮤온만 보면 우주선 뮤온 배경이 사라진다 (지구가 방패) — 센서 격자 위 시간 색 그라데이션 애니메이션

**F. CEvNS — 작은 검출기의 역설** (대표: COHERENT)
- ② 중성미자가 원자핵 전체를 한꺼번에 살짝 밈 → 아주 작은 되튐 → 극저잡음 검출기가 미세한 신호를 잡음
- ③ 되튐 에너지 (아주 작음)
- ④ 트릭: 원자핵 전체와 "결맞게" 반응해 확률이 크게 높아짐 → 킬로그램급 검출기로도 가능. 그러나 그 작은 되튐이 암흑물질 신호와 닮았다 → Bridge: Dark Matter (neutrino fog)

### 5. 최전선 — `frontier` · T4
- 열린 질문: **질량 순서** (normal vs inverted), **CP 위반** (물질–반물질 비대칭의 열쇠?), 절대 질량 (KATRIN 의 상한), **마요라나 입자인가?**
- **무중성미자 이중베타붕괴 (0νββ)**: 일어난다면 ν 는 자기 자신의 반입자
  - 원리 (P9 축약판): 붕괴하는 원자핵을 **검출기 자체** 로 만든다 → 두 전자의 에너지 합을 아주 정밀하게 잰다 → 보통의 이중베타붕괴는 중성미자가 에너지를 나눠 가져 넓게 퍼진 분포, 0νββ 라면 **끝점에 뾰족한 봉우리 하나**
  - 재는 방법 두 가지 그림: 극저온 결정의 미세한 온도 상승 (대표: CUORE/CUPID, LNGS · 같은 원리: **AMoRE, 예미랩**) / 게르마늄 반도체의 전하 (LEGEND → Bridge: Semiconductor)
  - 스펙트럼 위젯: 연속 스펙트럼 끝의 작은 봉우리 — 에너지 분해능이 나쁘면 봉우리가 묻히는 것을 체험
- 차세대: DUNE + Hyper-K + JUNO 의 상호보완
- 고에너지 천체 중성미자: IceCube 의 TXS 0506+056 (2018), **KM3-230213A** (~220 PeV, 2025 Nature)
- 초신성 조기 경보 (SNEWS)

## 대표 수치 (`src/data/`, 자릿수 수준)
- 지구에서 태양 중성미자 플럭스: ~10¹¹ /cm²/s (손톱 크기면 초당 수백억 개)
- 상호작용 단면적: GeV 에서 ~10⁻³⁸ cm²
- 검출기 규모: 수 kt (Super-K ~50 kt, JUNO ~20 kt) ~ 1 km³ (IceCube)
- 물에서의 체렌코프 각: ~42°
- 역베타붕괴 지연 시간: 수십 ~ 수백 μs
- 실험 목록: 이름, 위치, 방식, 대략적 크기만 (지도/갤러리용)

## 그래프 (모두 개략도)
- 진동 확률: 2-맛 공식으로 계산한 함수 그래프 (혼합각·Δm² 는 대략적 값)
- 출처별 에너지 스펙트럼: 에너지 축 위 위치만 나타내는 개형
- 0νββ: 연속 스펙트럼 끝의 작은 피크 개형
